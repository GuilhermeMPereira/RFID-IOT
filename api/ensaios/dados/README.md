# Dados dos ensaios

Os CSV desta pasta saem de `npm run metricas`, uma linha por condição
experimental, e alimentam o Quadro 5 do artigo.

## O que existe

`metricas-fff4a155-....csv` — verificação preliminar do instrumento, 17
tentativas em 7 condições, acumuladas ao longo do desenvolvimento. Não é a
execução do protocolo: as tentativas foram espaçadas por horas, o número
de repetições varia por condição e cinco leituras pegaram etiqueta sem
vínculo. Serve para mostrar que a cadeia de captura funciona, não para
estimar taxas. É o que a Subseção 4.3 relata.

## O que falta

A execução do protocolo descrito em `../../docs/protocolo-ensaios.md`:
cinco condições, dez repetições cada, num único ciclo, com todas as
etiquetas vinculadas antes de começar.
